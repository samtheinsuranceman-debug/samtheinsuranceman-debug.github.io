# Russell Capital Systems Domain Redirect

This repository hosts a minimal GitHub Pages redirect for `russellcapitalsystems.com` and `www.russellcapitalsystems.com`. The Pages custom hostname is the apex domain, whose GoDaddy records use GitHub’s four officially documented Pages A addresses. It sends visitors to the existing Russell Capital Systems website at `https://russellcap.com/` while preserving the requested path, query string, and fragment where possible.

The repository contains no credentials, customer data, tracking code, or application source. It is a reversible fallback created because GoDaddy accepted identity verification but did not persist forwarding edits or delete-recreate attempts.
